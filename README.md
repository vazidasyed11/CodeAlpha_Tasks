# CodeAlpha Internship Tasks

This repository contains my completed projects as part of the CodeAlpha Internship Program.

## 📌 Tasks Completed

### Task 2 – Exploratory Data Analysis
Performed Exploratory Data Analysis on the Titanic dataset using Python.
The project includes data cleaning, statistical analysis, visualization,
outlier detection, relationship analysis, and key insights.

### Task 3 – Data Visualization
Created meaningful charts and visualizations using Python, Pandas,
Matplotlib, and Seaborn to identify patterns and communicate insights clearly.

### Task 4 – Sentiment Analysis
Performed sentiment analysis on text data using Python and Natural
Language Processing techniques to classify text into positive,
negative, and neutral sentiments.
